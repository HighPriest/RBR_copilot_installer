# API reference

Generated by rustdoc from the code on every build of this site, private
items included: it is for working on the project, not a library to depend
on. The comments it shows are the ones in the code, so this is the
reference that cannot drift from it.

| Crate | What it holds |
|---|---|
| [`pacenotes_shared`](api/pacenotes_shared/index.html) | The protocol types both sides compile against: serde only. |
| [`pacenotes_server`](api/pacenotes_server/index.html) | The package and auth server: routes, the access decision, the store and `manifest gen`, conflict reports, the credential CLI. |
| [Installer — library](api/installer/lib/pacenotes_installer/index.html) | The installer's Win32-free logic: the tree and choice models, cache, ledger, engine, restore points, zip, sha256, the run log. |
| [Installer — application](api/installer/bin/pacenotes_installer/index.html) | The Windows binary: the wizard and its scenes, the worker thread, WinHTTP, the UI vocabulary, strings, elevation. |
| [`mdbook_repo_links`](api/mdbook_repo_links/index.html) | This book's preprocessor, which points links to repository files at GitHub. |

The installer's two halves share a crate name, so each has a reference of
its own. Their default server address is always the example one from
`installer/.env.example`, never a deployment's.

To build these pages locally, run `docs/build.sh`; see
[Development guide](DEVELOPMENT.md).
